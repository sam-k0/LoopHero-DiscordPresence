# Loop Hero Discord Presence

Additional game details shown on Discord.

![img](/res/Screenshot%202023-06-15%20124103.png)

Displays current state (In camp, expedition, etc..)

## Install

- Put `DiscordPresence.dll` into the `autoexec` directory.
- Put `discord-rpc.dll` into the game directory (next to `Loop Hero.exe`)

Make sure you installed the dependencies as usual.
